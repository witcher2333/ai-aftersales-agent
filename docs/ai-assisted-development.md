# AI 辅助开发与验证记录

本项目使用 AI 编码助手协助拆解需求、起草实现与 JUnit 测试，并由开发者逐项检查业务约束、调整代码和运行测试。可复用的拆解方式如下：

1. 将需求拆成模型接入、只读数据工具、输出校验、客服决定、界面展示五个边界。
2. 先列出不可违反的条件：工具只读、查询绑定当前工单、最多五轮、引用实际查询依据、决定由客服执行。
3. 用正常、信息缺失、数据冲突和越界调用案例起草测试，再检查测试是否真的会在错误实现下失败。
4. 针对测试失败定位是模型协议、业务数据、数据库状态还是环境配置问题；修复后重新运行相关测试。

本轮审查发现历史案例原先未按客户和商品隔离，因此收紧了 SQL 查询；同时给 JSON 输出增加服务端校验，避免只依赖提示词。协议测试用本地模拟 HTTP 服务验证请求格式与异常处理，不宣称已经调用真实 OpenAI 账号。正式简历中可写“使用 AI 编码助手辅助需求拆解、JUnit 测试初稿和问题排查，并审查修改后通过项目测试验证”；如需具体写“ChatGPT”，应以本人实际使用记录为准。
